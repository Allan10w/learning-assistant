## 1. 基线定义与规范

本项目采用 **Git Tag** 结合 **语义化版本 (SemVer)** 的方式进行基线管理。
*   **版本格式**：`v[主版本].[次版本].[修订号]-[阶段标识]`
*   **管理工具**：Gitee Release + Git Tags
